## ⚡ Overview & Product Story

**Ardian Living** started as a fun collaborative experiment among roomies living in Kost Ardian before modern AI tooling. It evolved across two major product iterations to solve real peer challenges: transparent boarding house room discovery and an automated peer-to-peer debt ledger.

---

## 🔄 Version Evolution

| Version | Branch | Architecture & Scope |
| :--- | :--- | :--- |
| **v2.0 (Current)** | `main` | **Fullstack Firebase PWA**: Realtime Firestore debt ledger, interactive video background, audio feedback, and mobile installable PWA. |
| **v1.0 (Prototype)** | [`v1-prototype`](https://github.com/zulilmiihsn/ardian-living/tree/v1-prototype) | **Static Showcase Prototype**: Local JSON profile modals, room amenities showcase, and GitHub Pages deployment. |

---

## ✨ Features (v2.0)

- 💳 **Realtime Peer Debt Ledger**: Powered by Firebase Firestore, allows residents to log, categorize, and settle shared living expenses and debts.
- 📱 **Progressive Web App (PWA)**: Installable directly onto mobile home screens with offline manifest support.
- 🛋️ **Interactive Media UI**: Custom video backgrounds (`bgDark.mp4`, `bgLight.mp4`) and tactile sound feedback on interactions.
