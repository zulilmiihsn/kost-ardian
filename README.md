## ⚡ Overview

**Kost Ardian** presents a digital showcase for students and professionals seeking accommodation. It solves discovery and inquiry friction by presenting room types, price tiers, amenities, rules, and instant contact channels.

## ✨ Features

- 🛋️ **Room & Facility Showcase**: Interactive galleries with detailed amenity listings (Wi-Fi, AC, bathrooms, parking).
- 📍 **Location & Vicinity**: Strategic access points and nearby campus/transit info.
- 📱 **Mobile Optimized**: Smooth, fast-loading responsive design for mobile browsers.
- 💬 **Direct WhatsApp Contact**: Seamless link for prospective tenants to schedule room viewings.

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router), React
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
